# Prologue

[Read](before-the-machine.pdf) · [Source](before-the-machine.tex)

Ten-page standalone opening: quarks, nuclear binding, D–T reaction bookkeeping, scattering and hot fuel. Not yet integrated into the thesis. The latest approved wording is preserved; packaging changes only dependency paths and source comments.

The four diagrams and their generator live in `figures/`. Schematics are not measured nuclear geometry; the binding-energy plot uses AME2020 and the barrier panel is a labelled toy calculation. [Data provenance](figures/source/data/README.md).

Build from the repository root with `python3 thesis/code/build.py prologue`. Review the wording before integration; replace overlapping thesis material rather than duplicating it.
