## The argument in three acts

1. **Build the vocabulary (§§1–50).** Start from controlled D–T fusion and let each failure of the simplest design force the next field, component or parameter into existence — no tokamak is presented in advance.
2. **Test the design (§§51–101).** Reconstruct Freidberg, Mangiarotti and Minervini (2015): at the conventional reference point the confinement-demanded current fails the kink screen (2/1.56 ≈ 1.28) and the independent current-drive affordability screen (0.84/0.44 ≈ 1.91); four remedies, four prices.
3. **Follow the consequences (§§102–127).** The published finite-A model closes the kink test (0.93) while bootstrap closure stays conditional on ~2.6 MA at the selected point of affordable drive; the centre stack then inherits every inboard obligation, quantified by a necessary current-area test and an explicit A_min boundary.

## Method

Motivate components before introducing them; define assumptions and units; derive load-bearing equations or cite accessible sources; keep measured results, empirical fits and hypotheses distinct. A model result is never reported as a demonstrated reactor capability.

## Status

Work in progress. Reconstructing Freidberg's two constraints is separate from proving reactor viability; the ST bootstrap/current-drive affordability comparison still needs an independent check. The research prospectus is a proposal to Professor Tan Yi — neither novelty nor acceptance is assumed.

## Local archives stay off GitHub

Keep superseded versions in a local `archive/` subfolder, such as `prologue/archive/`. The root `.gitignore` excludes folders named `archive` or `archives` at every depth, regardless of capitalization. Never stage, force-add, commit, or push their contents to the clean thesis repository. Publish only the current documents, their editable sources, and supporting assets; keep older working copies locally. Existing Git history is retained.
